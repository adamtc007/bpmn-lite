# EOP-RECON-CA-REUSE-001 — reuse recon: bpmn-lite

**Date:** 2026-09-09. **Tree:** branch `codex/bpmn-gameboard-refactor` (read-only recon; no fixes, no branches).
**Method:** direct source reads + three fan-out sweeps (hygiene families, domain-noun leakage, timer/instance-API capability), every claim cited `file:line`. Compile receipt: `cargo check -p bpmn-lite-engine -p bpmn-lite-store-postgres -p ffi-dispatcher -p ffi-types` — clean, 8.4s.

CA's use of bpmn-lite is exactly three things: (1) one fibre per event instance as a turn clock (named timer guards emitting one effect each); (2) the effect host (`AWAIT-EFFECT`, outbox/inbox relay, `EffectFailed{attempt}` with Transient/ContractViolation/BusinessRejection disposition); (3) nothing else.

---

## Headline

- **F-01 and F-02 are both CLOSED** (see BL-05). CA's posting-path prerequisites are met.
- The effect host is **generic, pub, and externally extensible** — an external crate implements one trait and registers it; no bpmn-lite source edit (BL-14).
- The **turn-clock is the gap**: timers exist and are durable/leased/correct, but they are unnamed, their deadlines are compile-time constants end-to-end, and a fire cannot declaratively emit a named effect (BL-02/03/04). CA's "N named timers from instance-start data, each emitting `clock.mark-deadline-passed`" does not exist as a declarable feature — the ISA and verifier already support the dynamic case; the compiler frontend and the start-payload path do not.
- One import blocker infects everything: `bpmn-lite-types::session_stack` hardcodes the ob-poc workspace taxonomy (`Kyc`, `Cbu`, `OnBoarding`, …) into the leaf types crate, the canonical byte encoding, the Postgres schema, and the **required** `StartCommand` shape — CA cannot start an instance without constructing an ob-poc-shaped value (BL-01).

- **bpmn-lite-kernel** — **importable now.** Pure (zero `&mut self`, zero SQL, zero todo), domain nouns only in tests. Transitively drags BL-01 via bpmn-lite-types.
- **bpmn-lite-types** — **importable after: BL-01.** The session_stack taxonomy is on the required start/instance/job shapes and in the canonical hash; CA cannot route around it.
- **bpmn-lite-store** — **importable after: BL-01** (trait surface carries the types; the crate itself is SQL-free and clean).
- **bpmn-lite-store-postgres** — **importable after: BL-01, BL-06.** Schema note in BL-12 (CA uses its own `ca` schema; do not add CA tables to `public`).
- **bpmn-lite-engine** — **importable after: BL-01** for the effect-host half of CA's use; **the turn-clock half additionally needs BL-02, BL-03, BL-04** (capability gaps, not import blockers).
- **bpmn-lite-compiler** — **importable after: BL-01 (transitive), BL-07; BL-10** cosmetic.
- **ffi-types / ffi-catalogue / ffi-dispatcher** — **importable now.** Clean, generic, pub; the effect-adapter extension point works without modification.
- **bpmn-lite-server-runner / bpmn-lite-server-designer** (binaries) — **not importable** as CA serving surfaces (BL-08; designer additionally embeds ob-poc manifests and pulls the dsl git deps). CA embeds the engine instead.

## CA-needs-that-do-not-exist-here

1. **Named timer guards with per-instance deadlines from start data, each emitting one named effect on fire** (BL-02+03+04). Kernel/verifier already support dynamic durations off the operand stack; missing pieces are (a) a start-payload→flag (or payload→stack) seeding path — currently rejected by design F-DSGN-1 (`grpc.rs:539-548`), (b) compiler emission of `LoadFlag` before arm words instead of `PushI64(const)`, (c) a timer name in the artifact + on `RuntimeEvent::TimerFired`, (d) declarative fire→effect (or the documented convention: non-interrupting guard + handler fibre running the effect).
2. **Monotonic-within-ms uuidv7 helper** (BL-11) — no helper exists anywhere; bare `Uuid::now_v7()` is not monotonic within a millisecond. Belongs in sem-os; bpmn-lite consumes.
3. **Decimal/scaled-integer numeric kind** in the IR and `SchemaKind` (BL-07) — until then, `"decimal"` silently means IEEE-754.
4. **Compiler frontend for race constructs** (`V2RaceOpen`/`V2ArmTimer`/`V2ArmEffect`) — kernel-complete, fixture-proven, unreachable from any source language.
5. **External terminate** — only `cancel` exists; likely sufficient for CA, listed for completeness.
